# Focus Clock

**Make the goal you care about visible. See where today is going, then choose one next action.**

Focus Clock is a visual day planner built around an analog clock face. Put activities on the dial, see what is happening now and next, and start a focus timer when you are ready. The clock is a view of your intentions and your day—not a scorecard.

## Use it

- Add an activity from the clock face or the activity form, then set its time and duration.
- View the day as clock arcs or switch to the agenda when a list is easier to read.
- Start a focus session from an activity and return to the clock to see how your day is unfolding.
- Use the assistant to talk through a goal and, when connected to a scheduling-capable AI provider, create or adjust time blocks.
- Keep using the planner offline. Optional AI and calendar connections need network access and their own provider credentials.

There are no streaks to protect. A changed plan is still a useful reflection of the day you actually have.

## Project direction

Focus Clock exists to keep a meaningful intention in view and make the next action easier to begin. It is part of a wider ecosystem with Sadar and Fitrah Launcher; each app should remain useful on its own while sharing a clear path into the others.

Read the [manifesto](MANIFESTO.md) and the [unclogged canvas build direction](docs/product/FOCUS-CLOCK-UNCLOGGED-CANVAS.md).
